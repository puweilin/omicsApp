# omicsApp: Shiny Web Interface for Multi-Omics Analysis

Interactive Shiny application for proteomics and transcriptomics
analysis, powered by the
[omicsCore](https://github.com/puweilin/omicsApp) engine.

## Details

The entry point is
[`launch()`](https://puweilin.github.io/omicsApp/omicsApp/reference/launch.md).
