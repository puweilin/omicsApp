## 1. 严重问题（会给出错误结论）——已修复

### 1.1 元数据按行位置而不是按样本名对应（A1-C1/C2）
- **现象**：样本表行序与矩阵列序不同（很常见，例如样本表按组排序）时，分组/协变量被错位地分给样本。
  连续变量分析的 p 值从 2.9e-7 变成 0.057；找不到匹配列时还会**静默按位置**赋值，组别可能整体颠倒。
- **修复**：`materialize_metadata()` 按样本名匹配（数值 ID 不再写成 `1e+05`；大小写/标点不同的 ID 宽松匹配并提示），
  多出/缺少的样本行写入导入报告而不是报错；匹配不上时**不再按位置赋值**，而是不附加元数据并说明原因。
  `omics_input()` 构造时自动按矩阵顺序重排，`validate_omics_input()` 拒绝顺序不一致、重复样本名、非数值矩阵、
  `feature_id` 与行名不符的输入。

### 1.2 线性尺度数据被当作 log2 数据分析（A2-H1/H2）
- **现象**：`raw_intensity`、TPM/FPKM 以及用 limma / t-test / lm 分析的原始计数，直接在线性尺度上拟合，
  结果却标成 log2 fold change；计数数据用 t-test 不做文库大小校正，模拟数据中 500 个基因有 347 个"显著"。
- **修复**：新增 `prepare_diff_scale()`：计数 → TMM 校正的 log2-CPM，线性强度/TPM/FPKM → log2(x+1)；
  结果中记录 `assay_type`（原始）与 `analysed_scale`（实际分析尺度），并在 `warnings` 中说明。

### 1.3 edgeR 不过滤低表达基因（A2-H3）
- **现象**：没有 `filterByExpr()`，真实差异基因 24 个只检出 1 个。
- **修复**：两组比较和全局检验都先过滤；被过滤的基因以 NA 行保留（每个基因都还在表里），并注明过滤了多少。

### 1.4 RNA-seq QC 在原始计数上找离群样本，并自动删除（QC / A5）
- **现象**：相关性/PCA 直接用原始计数，测序深的文库被判为离群（z = -3.81，log-CPM 上是 +1.36），
  然后被 `run_qc()` **静默删除**，一组 3 个样本可能变成 2 个。
- **修复**：离群检测和 QC PCA 一律在 log 尺度（计数为 log2-CPM）上做；被标记的样本**默认保留**并给出提示，
  需要删除时显式 `remove_outliers = TRUE`；样本数 ≤ 10 时 z 阈值 3 根本达不到，结果会说明并建议看 PCA 图。

### 1.5 线性强度的插补产生负值（A1-H6）
- **现象**：MinProb 等左删失方法假设 log 正态，在原始强度上插补出负强度，`assay_type` 也不变。
- **修复**：线性强度在 log2 尺度插补后再变换回去，只替换原本缺失的格子；log 强度插补后标记为
  `imputed_intensity`；插补图改为"观测值 vs 插补值"（原来与 `raw_mat` 比，尺度都不一样）。

### 1.6 可复现脚本漏掉了应用内的归一化（A3-C1）
- **现象**：应用里做过 vsn/log2 归一化的蛋白组层，`export_script()` 生成的脚本按"已归一化"读入原始文件，
  后续所有分析都在线性数据上跑；sheet 角色与研究设计也没有写进脚本。
- **修复**：`normalize_omics()` 记录方法/偏移量/原始 assay；脚本按原始 assay 读入 → `normalize_omics()` →
  `set_study_design()`，并带上 `sheet_roles`；子集操作保留来源与处理记录。

### 1.7 保存项目的路径穿越（A4-M7，安全）
- **现象**：打开/删除已保存项目时，项目名来自浏览器输入，`../victim` 可以读取或**删除存储目录以外的文件**。
- **修复**：`is_stored_slug()`：只接受 `project_slug()` 能产生的名字，保存/打开/删除三处都校验。

## 2. 其他已修复问题

### 差异分析（A2）
- edgeR 全局检验按名字前缀找组系数，名为 `group_batch` 的协变量也被当成组一起检验 → 改用 `model.matrix` 的 `assign`。
- limma 样条模型因参数名与 `run_diff(method=)` 冲突而无法调用，`df` 被忽略 → 参数改名 `model = "spline"`。
- 协变量的某个因子水平只出现在比较组之外时被误判"混杂" → 校验前 `droplevels()`。
- 全局检验跳过设计校验：协变量含 NA 直接崩溃，`selected_groups` 拼错静默忽略 → 与两组比较共用校验。
- 配对设计 + 个体层面协变量（如性别）使 DESeq2/edgeR 崩溃 → 提前给出"该协变量在区组内不变"的明确错误。
- limma 连续变量分析把数值型配对 ID 当成斜率 → 作为因子；非语法列名（如 `Treatment Group`）在 DESeq2/edgeR/lm 中崩溃 → 占位列名/反引号。
- edgeR 对 scaledTPM 的 tximport 输入错误使用 offset → 仅 `countsFromAbundance = "no"` 时使用。
- 多对比结果直接画火山图/MA 图会把所有对比混在一起 → 要求先 `select_comparison()`。
- DESeq2 离散度拟合回退时静默 → 给出"p 值偏乐观"的警告；火山图阈值 `>` 与表格 `>=` 不一致 → 统一为 `>=`。

### 导入（A1）
- 一个 `#DIV/0!`、`<LOD`、`n.q.` 单元格会让整列样本被丢弃 → 读作缺失并计数提示；被当作注释排除的列也会列出。
- readxl 只看前 1000 行猜类型 → `guess_max` 覆盖全表；`;` 分隔的 CSV 默认小数点为逗号（原来被当作千分位，值放大 1000 倍）。
- 带重复/NA 的数值 ID 列被当成样本；重复 feature ID 使 `feature_df` 与矩阵行名不一致导致 QC 崩溃。
- 全空列被当作非数值列而非"无数据的列"。

### QC
- `knn` 插补不能指定近邻数（`K`/`k` 都报错）；`normalize_omics()` 在 `assay_type` 为 NULL 时崩溃。
- 连通性计算在无缺失时改用整体相关矩阵（60k × 300 时原来要 47 秒）。

### 富集 / 整合 / 导出（A3）
- **GSEA 排序**：原来按未收缩的效应量排序，未检验（p 为 NA）的基因也参与，重复基因保留"最正"的值（整体偏向上调）
  → 改为带符号的检验统计量（t / Wald；edgeR 的 F 取 √F 带符号；其余用 sign·-log10 p），只用有 p 值的基因，
  重复基因保留绝对值最大者；使用的排序指标记录在 `params$rank_metric`。
- **ORA**：`min_size`/`max_size` 原来没传给 `enricher()`；背景集包含了未检验的基因 → 背景改为实际检验过的基因。
- **ActivePathways**：GMT 基因未做大小写统一（小鼠基因集完全匹配不上）；默认背景是 GMT 全部基因（偏宽松）
  → 统一键、背景 = 实测基因 ∩ 基因集；p 为 NA 记为 1。
- **GSVA**：基因集大小在与实测基因取交集**之前**过滤；`gene_sets_supplied` 逻辑反了；计数用 log2(x+1) 不校正文库；
  重复 symbol 保留第一行 → 交集后过滤、修正标记、log2-CPM、保留表达最高的行；自定义基因集导出脚本时给出说明。
- **Concordance**：象限计数原来统计所有特征 → 改为两层都显著的特征（另保留 `quadrant_counts_all`），象限图同步。
- `output_p_cutoff` 写入 `params`（脚本可复现）；`export_bundle()` 遇到 ActivePathways 的 list 列崩溃，
  文本中的制表符/换行会错位 TSV → 统一展平。

### Shiny 应用（A4）
- **异步竞态**：差异分析、全局检验、富集、多对比富集的结果晚到时会落到已切换的图层/项目上
  → 新增 `run_epoch()`，每次运行/重置取新编号，过期结果直接丢弃；运行中按钮重绘不再变成可点击（避免并行运行）。
- **打开/恢复/示例项目**：新项目与当前项目来自相同文件时，视图里旧结果会覆盖新项目保存的结果
  → 项目整体替换时通知所有视图清空。
- **删除图层**：基于该图层计算的结果仍留在项目里（报告、脚本都会带上）→ 一并删除。
- **切换图层后旧富集结果仍显示**并以新图层名义进入项目 → 上游结果清空时富集也清空。
- 每次运行后 Method / 协变量控件被重置为 auto/空 → 保持用户选择。
- 没有可重复分组列时退回到样本 ID 列作为分组 → 只提供至少有重复值的列，否则给出明确提示。
- 零图层项目使差异视图报错；保存项目后名称仍是 "User project"；富集"N of M selected"用的是实时阈值而非运行时阈值；
  没有 LaTeX 时 PDF 按钮仍可点击 → 均已修复。
- QC 视图：显示"标记但保留"的离群样本及 QC 过程说明。

### 打包（A5）
- `R CMD check` 的 ERROR（测试读取源码文件）、WARNING（R 代码中的非 ASCII 字符）、NOTE（未声明的全局变量）已处理；
  去掉无 `data/` 的 `LazyData`；`has_pkg()` 改为只检查是否安装（原来会加载 DESeq2 等，打开视图多花 6 秒）；
  API 契约测试不再把 `x` 文件写进仓库目录，已删除误提交的 `x/` 测试产物。
