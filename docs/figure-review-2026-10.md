# 网页图表专项审查（2026-10）

对应用中展示的全部图表（以及导出报告中的图）做了逐张检查：在真实浏览器中，用三组数据
（内置教程、"真实规模"4 组蛋白组 + 配对 RNA-seq、"压力"6 组长组名 60 样本）分别在桌面（1440 px）、
手机（390 px）和高分屏（2×）下截图；同时测量了渲染耗时与数据量，并用 dataviz 规范的配色校验脚本检查色盲安全性。

## 1. 图表清单

| 页面 | 图 | 绘制方式 |
|---|---|---|
| QC | PCA（按组着色+形状）、缺失率（每样本 + 每特征）/ 测序深度 | 静态 PNG（ggplot2，96 dpi，高分屏自动 2×） |

## 2. 发现的缺陷（已修复，均有回归测试）

| 问题 | 影响 | 修复 |
|---|---|---|
| **共享差异图（UpSet）点阵与柱子错位**：只要存在任何多个对比共有的差异，下方点阵的列顺序就由"连线"图层决定，与上方柱子不对应 | 正确性问题：图会告诉读者错误的交集（例如把"仅 TreatA"的 161 个标成"TreatA 与 TreatB 共有"）；真实数据几乎总会触发 | 两个面板使用同一组明确的 x 轴顺序 |
| 交互火山图的"标注前 20 个"开关无效 | ggplotly 不能转换 ggrepel 文字图层，静默丢弃 | 改用 plotly 原生标注 |
| 浏览器不支持 WebGL 时火山图一片空白（只显示"WebGL is not supported"） | 远程桌面、无 GPU 或受限电脑上看不到火山图 | 浏览器连接时报告是否支持 WebGL，不支持则用 SVG 绘制 |
| 手机宽度下富集点图被右侧图例挤成一条线，整合图图例截断 | 手机上无法阅读 | 窄屏时图例移到下方、横排、逐行堆叠，标题在上；分组图例保持单列 |
| 报告中的 PCA 没有按组着色 | 报告读者看不出样本是否按条件聚类 | 按图层的分组列着色 |
| 火山图悬停提示显示原始列名（`adj_p_value`、`effect`） | 与界面统一术语不一致 | 改为 log2FC / adjusted p |

## 3. 优化建议（未改动，按优先级）

### 高优先级：影响解读

1. **火山图按方向着色**：目前所有显著点都是红色，下调也是红色；而"每个对比的上/下调数"图中下调是蓝色。建议上调红、下调蓝，与全应用一致。同时：x 轴以 0 对称（便于比较上下调幅度），画出 fold-change 阈值竖线。
2. **交互火山图丢失阈值说明**：plotly 不显示 ggplot 的副标题和图注，界面里看不到"显著 = adjusted p < 0.05"。建议在卡片上用文字给出，或作为 plotly 标注。
3. **整合页"dual volcano"命名与内容不符**：x 轴实际是"两层效应之差"，并不是双火山图。建议改名为"两层差异的差值"并在卡片说明；坐标轴写 log2FC；图例用通俗说法（"两层均上调""未同时显著"代替 `up_up`、`n/a`）。
4. **标签过多重叠**：整合图强制标注全部标签（`max.overlaps = Inf`），在密集区出现大量交叉引线。建议限制重叠（如 10），只标注显著且最极端的若干个，并让灰色背景点半透明、显著点画在最上层。
5. **QC 缺失率面板难读**：每样本缺失率的 x 轴固定为 0–100%，而实际多在 10–20%，柱子挤在左侧；超过约 20 个样本时样本名重叠；每特征的"密度"曲线对生物学用户不直观。建议：样本面板按数据范围缩放并标出超出阈值的样本；特征面板改为直方图或累积曲线，并画出当前"缺失率阈值"滑块对应的竖线和"将删除 N 个特征"。
6. **富集点图重复编码**：x 轴和点大小都表示重叠基因数，颜色由一个极端值主导（其余几乎都是灰色）。建议 x 轴改为基因比例或 -log10(p)，颜色上限按分位数截断或改用方向色；同时可去掉多余的大小图例（也解决手机上的图例宽度问题）。

### 中优先级：可读性与一致性

7. **标题重复且带术语**："PCA of cleaned input""Volcano""Enrichment"与卡片标题重复。建议应用内去掉图内标题（卡片已有），报告中保留但用通俗说法。
8. **分组配色色盲不安全**：PCA 分组使用 ggplot 默认色相，校验脚本显示绿色与橄榄色在绿色盲下几乎无法区分（ΔE 4.0，阈值 8）。目前 ≤6 组时已有形状作为第二编码；建议换成经过校验的分类色板（参考色板 6 色全部通过）。
9. **多对比通路图**：报告中副标题与右侧图例重叠；全部显著时"adjusted p < 0.05: yes"图例无信息量；大小用未校正的 -log10 p，与其他地方不一致。
10. **手机上的 UpSet 图**：5 个以上对比时组名占去大半宽度，柱子标签重叠。建议窄屏时改为表格或只显示前几个组合。
11. **报告图尺寸统一为 1344×864**：通路很多或很少时都同一高度；建议按内容（行数）设定高度，并考虑矢量格式（SVG）以便放大和发表。

### 建议新增：提升实用价值

12. **更多交互**：PCA 悬停显示样本名（识别离群样本最需要）；整合散点悬停显示基因名；富集点图悬停显示重叠基因。
13. **图片下载**：除火山图外，其他图没有单独下载按钮。为生物学用户提供"下载 PNG（300 dpi）/ PDF / SVG"会很有价值。
14. **启用已有但未展示的图**：点击结果表中的基因 → 显示该基因按组的表达箱线图；显著差异基因热图；选中通路的 GSEA 富集曲线。这些核心函数已经存在。
15. **大数据量火山图**：6 万点时交互版需要向浏览器传 3.6 MB；可以对远离阈值、互相重叠的不显著点做抽稀，在外观不变的前提下大幅减小数据量。

## 4. 性能与清晰度

- 服务器端每张静态图绘制 0.2–0.5 秒；6 万点火山图静态 1.5 秒、交互版构建 1.6 秒。
- 高分屏下静态图按 2× 分辨率渲染，清晰。
- 页面切换耗时主要来自分析与数据准备（QC 约 4 秒、差异页约 10 秒，含火山图与三张汇总图），不在绘图本身。
