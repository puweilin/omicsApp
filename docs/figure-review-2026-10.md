# 网页图表专项审查（2026-10）

对应用中展示的全部图表（以及导出报告中的图）做了逐张检查：在真实浏览器中，用三组数据
（内置教程、"真实规模"4 组蛋白组 + 配对 RNA-seq、"压力"6 组长组名 60 样本）分别在桌面（1440 px）、
手机（390 px）和高分屏（2×）下截图；同时测量了渲染耗时与数据量，并用 dataviz 规范的配色校验脚本检查色盲安全性。

## 1. 图表清单

| 页面 | 图 | 绘制方式 |
|---|---|---|
| QC | PCA（按组着色+形状）、缺失率（每样本 + 每特征）/ 测序深度 | 静态 PNG（ggplot2，96 dpi，高分屏自动 2×） |
| 差异 | 火山图 | 交互（plotly，WebGL） |
| 差异 | 每个对比的上/下调数、共享差异（UpSet） | 静态 |
| 富集 | 通路点图、多对比通路点图 | 静态 |
| 整合 | 两层差异图（"dual volcano"）、效应对比散点、相关散点、ActivePathways 点图 | 静态 |
| 报告 | 上述多数图的同款静态版本 | 静态 PNG（1344×864） |

核心包里还有 MA 图、热图、单基因表达箱线图、GSEA 曲线、GSVA 热图，目前应用中没有入口。

## 2. 发现的缺陷（已修复，均有回归测试）

| 问题 | 影响 | 修复 |
|---|---|---|
| **共享差异图（UpSet）点阵与柱子错位**：只要存在任何多个对比共有的差异，下方点阵的列顺序就由"连线"图层决定，与上方柱子不对应 | 正确性问题：图会告诉读者错误的交集（例如把"仅 TreatA"的 161 个标成"TreatA 与 TreatB 共有"）；真实数据几乎总会触发 | 两个面板使用同一组明确的 x 轴顺序 |
| 交互火山图的"标注前 20 个"开关无效 | ggplotly 不能转换 ggrepel 文字图层，静默丢弃 | 改用 plotly 原生标注 |
| 浏览器不支持 WebGL 时火山图一片空白（只显示"WebGL is not supported"） | 远程桌面、无 GPU 或受限电脑上看不到火山图 | 浏览器连接时报告是否支持 WebGL，不支持则用 SVG 绘制 |
| 手机宽度下富集点图被右侧图例挤成一条线，整合图图例截断 | 手机上无法阅读 | 窄屏时图例移到下方、横排、逐行堆叠，标题在上；分组图例保持单列 |
| 报告中的 PCA 没有按组着色 | 报告读者看不出样本是否按条件聚类 | 按图层的分组列着色 |
| 火山图悬停提示显示原始列名（`adj_p_value`、`effect`） | 与界面统一术语不一致 | 改为 log2FC / adjusted p |

## 3. 优化建议（未改动，按优先级）

### 高优先级：影响解读

1. ✅ **已完成（见第 6 节）** **火山图按方向着色**：目前所有显著点都是红色，下调也是红色；而"每个对比的上/下调数"图中下调是蓝色。建议上调红、下调蓝，与全应用一致。同时：x 轴以 0 对称（便于比较上下调幅度），画出 fold-change 阈值竖线。
2. ✅ **已完成（见第 6 节）** **交互火山图丢失阈值说明**：plotly 不显示 ggplot 的副标题和图注，界面里看不到"显著 = adjusted p < 0.05"。建议在卡片上用文字给出，或作为 plotly 标注。
3. ✅ **已完成（见下文第 5 节）** **整合页"dual volcano"命名与内容不符**：x 轴实际是"两层效应之差"，并不是双火山图。建议改名为"两层差异的差值"并在卡片说明；坐标轴写 log2FC；图例用通俗说法（"两层均上调""未同时显著"代替 `up_up`、`n/a`）。
4. ✅ **已完成（见第 5、6 节）** **标签过多重叠**：整合图强制标注全部标签（`max.overlaps = Inf`），在密集区出现大量交叉引线。建议限制重叠（如 10），只标注显著且最极端的若干个，并让灰色背景点半透明、显著点画在最上层。
5. ✅ **已完成（见第 6 节）** **QC 缺失率面板难读**：每样本缺失率的 x 轴固定为 0–100%，而实际多在 10–20%，柱子挤在左侧；超过约 20 个样本时样本名重叠；每特征的"密度"曲线对生物学用户不直观。建议：样本面板按数据范围缩放并标出超出阈值的样本；特征面板改为直方图或累积曲线，并画出当前"缺失率阈值"滑块对应的竖线和"将删除 N 个特征"。
6. ✅ **已完成（见第 6 节）** **富集点图重复编码**：x 轴和点大小都表示重叠基因数，颜色由一个极端值主导（其余几乎都是灰色）。建议 x 轴改为基因比例或 -log10(p)，颜色上限按分位数截断或改用方向色；同时可去掉多余的大小图例（也解决手机上的图例宽度问题）。

### 中优先级：可读性与一致性

7. **标题重复且带术语**："PCA of cleaned input""Volcano""Enrichment"与卡片标题重复。建议应用内去掉图内标题（卡片已有），报告中保留但用通俗说法。
8. **分组配色色盲不安全**：PCA 分组使用 ggplot 默认色相，校验脚本显示绿色与橄榄色在绿色盲下几乎无法区分（ΔE 4.0，阈值 8）。目前 ≤6 组时已有形状作为第二编码；建议换成经过校验的分类色板（参考色板 6 色全部通过）。
9. **多对比通路图**：报告中副标题与右侧图例重叠；全部显著时"adjusted p < 0.05: yes"图例无信息量；大小用未校正的 -log10 p，与其他地方不一致。
10. **手机上的 UpSet 图**：5 个以上对比时组名占去大半宽度，柱子标签重叠。建议窄屏时改为表格或只显示前几个组合。
11. **报告图尺寸统一为 1344×864**：通路很多或很少时都同一高度；建议按内容（行数）设定高度，并考虑矢量格式（SVG）以便放大和发表。

### 建议新增：提升实用价值

12. **更多交互**：PCA 悬停显示样本名（识别离群样本最需要）；整合散点悬停显示基因名；富集点图悬停显示重叠基因。
13. **图片下载**：除火山图外，其他图没有单独下载按钮。为生物学用户提供"下载 PNG（300 dpi）/ PDF / SVG"会很有价值。
14. **启用已有但未展示的图**：点击结果表中的基因 → 显示该基因按组的表达箱线图；显著差异基因热图；选中通路的 GSEA 富集曲线。这些核心函数已经存在。
15. **大数据量火山图**：6 万点时交互版需要向浏览器传 3.6 MB；可以对远离阈值、互相重叠的不显著点做抽稀，在外观不变的前提下大幅减小数据量。

## 4. 性能与清晰度

- 服务器端每张静态图绘制 0.2–0.5 秒；6 万点火山图静态 1.5 秒、交互版构建 1.6 秒。
- 高分屏下静态图按 2× 分辨率渲染，清晰。
- 页面切换耗时主要来自分析与数据准备（QC 约 4 秒、差异页约 10 秒，含火山图与三张汇总图），不在绘图本身。

## 5. 后续：整合页图表重做（已完成）

- **去掉 dual volcano**：它的 x 轴是两层效应之差、y 轴是 Fisher 合并 p，把两层最一致的基因画在中间（读者会理解为"无变化"）。应用和报告中不再显示；`plot_integration(view = "dual_volcano")` 保留但会给出弃用警告，新导出的复现脚本不再调用它，旧脚本仍可运行。
- **效应对比散点图**（`view = "effect_pair"`）：两层 log2FC 等比例坐标、以 0 对称，虚线为完全一致的对角线；只有两层都显著的点着色（两层均上调 / 均下调 / 方向相反，图例带数量），其余为半透明灰色背景；前 8 个 top hits 加圈并标注，标签沿远离对角线的方向排开，避免挤在一起。
- **新增 top hits 哑铃图**（`view = "top_hits"`）：每行一个基因，蓝色圆点为第一层、橙色方块为第二层（色盲校验通过，并用形状做第二编码），中间连线越短两层越一致，跨过 0 的连线即方向相反。
- 排序沿用现有方法：两层都显著的基因按合并后的 adjusted p 排序，与结果表顺序一致。
- 应用里的整合页：第一行是散点图和 top hits 卡片（12 个）；报告中散点图后增加 top hits 图（15 个）。

## 6. 后续：高优先级建议全部完成

- **火山图**（`plot_volcano()`，MA 图同步）：上调红、下调蓝、不显著灰色并画在底层，图例带数量（如"up (5)""down (112)"）；x 轴以 0 对称；画出 ±倍数变化阈值虚线。全局检验（F 统计量）没有方向，仍用单一颜色；连续变量分析写作 positive / negative。
- **火山图跟随阈值**：应用里的火山图改为按当前的 p 值类型、p 阈值和 |log2FC| 阈值绘制，与旁边的结果表和统计卡片一致；卡片标题下写明"significant = adjusted p < 0.05 and |log2FC| ≥ 0.263"，随控件变化。报告和导出的复现脚本使用项目保存的同一组阈值，所以三处的图一致。
- **整合散点图**（相关性分析）：最多标注 8 个，且只标注显著的基因（用户指定的除外）；不显著的点半透明画在底层；横轴写"Spearman correlation across paired samples"。
- **QC 缺失率面板**：每样本面板有自己的坐标范围（不再被 100% 缺失的特征拉到 0–100%）；样本多于 10 个时改为排序点图并在副标题列出最差的样本，避免名字重叠；设置了样本阈值时画虚线并用琥珀色标出超标样本。每特征面板改为 0–100% 的直方图（按可能取值分箱，平方根纵轴，使被删除的少量特征也看得见），画出过滤阈值虚线，被删除的柱子用琥珀色，副标题写明"3,000 features · 308 removed (missing in more than 50% of samples)"。按组过滤时画的是组内缺失率，说明文字随之改变。
- **富集点图**：ORA 的 x 轴改为"通路基因中在列表里的比例"，点大小为基因数，颜色为显著性，三者不再重复；颜色上限按离群值截断（标为"≥ 15"等），其余通路不再全是灰色。GSEA 保持 x = NES。手机宽度下图例不再被截断。

## 7. 后续：剩余三项也已完成

- **交互火山图标签**：开启后，上调基因的标签排在右侧一列、下调的排在左侧一列，按点的高度依次堆叠，间隔固定，互不重叠；x 轴对称加宽以容纳标签列。放不下或离点太远的标签从最不显著的开始省略（真实数据上约显示 9–11 个），悬停仍可看到每个基因名。开关改名为"Label top hits (up to 20)"。图内重复的"Volcano"标题去掉（卡片已有标题，手机上它与工具栏重叠）。
- **QC 测序深度视图**：与缺失率面板使用同一套规则——最多 10 个样本画带名字的条形，超过则改为排序点图并在副标题列出最低的样本；最低的样本在最上方；文库过浅（低于中位数 30%）的样本在两个面板都用琥珀色标出并画阈值线；坐标轴从 0 开始，标签写作 50k、2.5M。两个 QC 面板的阈值虚线下加白色衬底，穿过深色柱子时仍清晰可见。
- **富集条形图**：颜色改为方向——上调列表红、下调列表蓝，GSEA 按 NES 正负着色并加图例，无方向时用深色单色；极端值不再把其余条形压扁：超过其余最长条 3 倍时截断到该长度，画两道白色断裂标记，并在末端写出真实值（如"248"）。
- **蛋白组的"Library size"**：蛋白组图层的深度视图改称"Total intensity per sample / Features quantified per sample"，过低的样本写作"low total intensity"，应用里的选项和卡片标题改为"Intensity"，说明写"median total intensity 114G"。同时修正了计算：log2 强度图层的总强度此前是直接把 log 值相加，上样量只有五分之一的样本也只低约 1%、从不会被标出；现在先还原到线性尺度再求和。坐标轴单位增加 G（十亿）和 T。

## 8. 后续：中优先级的多对比通路图，以及"建议新增"的四项

- **多对比通路比较图**（`plot_enrichment_comparison()`）：副标题拆成两短行，图例放在副标题下方，不再重叠；"adjusted p < 0.05"的实心/空心图例只在确实有空心点时出现；点大小的图例改为"-log10(adjusted p)"并按离群值截断（"≥ 33"）；对比共用同一对照时列名只写处理组，对照写在副标题里；应用里图的高度随通路行数增加。
- **悬停显示名称**：QC 的 PCA、整合页的效应对比散点图、top hits 哑铃图、相关性散点图和 ActivePathways 点图，鼠标悬停（手机上点按）会显示样本名或基因名及对应数值；图仍是静态 ggplot，没有改成 plotly。
- **单独下载每张图**：14 张图的卡片右上角都有下载按钮，提供 PNG（300 dpi）、PDF、SVG；文件按桌面版布局绘制（手机上下载也一样），文件名形如 `项目_volcano_TreatA_vs_Control.pdf`。交互火山图下载的是同阈值的静态版本，包含全部点。SVG 中的文字为轮廓（服务器上没有 svglite）。
- **点击查看**：差异页点击结果表的基因（或点击火山图上的点）会打开"Selected feature"卡片，显示该基因在各组的表达箱线图（计数数据用 log2(CPM+1)），火山图上圈出该点；新增显著基因热图卡片（最多 50 个，按组分块、逐行 z-score，选中的基因加框）。富集页点击通路：GSEA 显示富集曲线，ORA 显示重叠基因及其 log2FC。
- **火山图抽稀**：超过 5,000 个特征时，只对密集的不显著点按屏幕网格抽稀，显著点、标注点、选中的点全部保留，图例写明"thinned for display: N of M shown"。6 万点时传给浏览器的数据从约 5.2 MB 降到 0.18 MB，构建时间从约 2 秒降到 0.5 秒。报告和导出的静态图不抽稀。
