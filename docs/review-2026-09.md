1. **示例项目 `tutorial_project()`**（`R/tutorial.R`）。这是一个真实的 `omics_project`，
   专门设计成每一步都有东西可发现：

## 4. 一次上传包含多个组别（1 个对照 + 多个处理）时如何处理

### 原来的框架

- 每次只能做一个 `case vs control` 对比，而且**只用这两组的样本**拟合模型：
  其他组的样本被丢掉，方差不共享，limma 损失自由度，DESeq2/edgeR 的离散度也只用两组估计。
  先跑 B vs A、再跑 C vs A，得到的是两个互不相关的模型。
- 默认 control 是**字母序第一个**组：`Treated` / `Vehicle` 这样的组名会把 Treated 当成对照。
- 结果只有一个槽位，跑新的对比就覆盖旧的。
- limma 在组名不是合法 R 名字（"24h"、"Drug A"、"KO-1"）时直接失败：
  `makeContrasts()` 只接受合法名字。edgeR 用子串匹配找系数，"AB" 会被当成 "A"。
- ANOVA 的 F 检验用的是 cell-means 设计（`~0+group`），检验的其实是"所有组均值 = 0"，
  在 log 强度上几乎所有特征都显著。

### 现在的设计：共享模型 + 堆叠结果 + 视图选择

```r
b <- run_diff(input, group_col = "treatment", control_group = "DMSO",
              case_group = c("DrugA", "DrugB", "DrugC"))
diff_comparisons(b)                   # "DrugA_vs_DMSO" "DrugB_vs_DMSO" "DrugC_vs_DMSO"
summarize_diff_contrasts(b)           # 每个对比的上调/下调数，以及和其他对比共享的命中数
plot_diff_contrasts(b)                # 发散条形图
a <- select_comparison(b, "DrugA_vs_DMSO")   # 一个普通的单对比 bundle
run_enrichment(a, ...); run_integration(..., diff_bundles = list(prot = a, rna = ...))
```

- **一次拟合**：limma / DESeq2 / edgeR 把 control 和所有 case 放进同一个模型，
  逐个对比地取结果，各对比共享残差方差（离散度）和 eBayes 先验。
  t 检验和 lm 没有共享模型，退化为逐对运行。
- **结果堆叠**：`diff_result_df` 里的多个对比靠已有的 `comparison` 列区分，不需要改 schema。
  只有一个 case 时，结果和原来逐位相同（有测试保证）。
- **`select_comparison()` 是关键接口**：它返回一个和单对比完全同形的 bundle，
  所以火山图、富集、整合、报告、脚本导出都不用改。
  它同时记录 `all_case_groups`，整合视图靠这个在搭档层上复现同一个共享模型。
- **配对设计**：多组时，允许每个 block（donor）包含 control 和至少一个处理组。
- **修复**：limma 设计矩阵的列改用占位名，组名不再受限；edgeR 按精确列名找系数；
  ANOVA 改为 `~group` 并检验 `coef = 2:k`。

### Differential 视图

- **Control (reference)**：自动识别常见的对照组名（control / ctrl / DMSO / vehicle / WT /
  untreated / sham / baseline / 0h …），识别不到时才退回字母序第一个。
- **Compare against control**：可以多选，默认选中除对照外的所有组。
- **Showing**：选择页面上显示哪个对比。Enrichment、Integration 和报告都跟随这个选择。
- **Comparisons 卡片**：只在有多个对比时出现，显示每个对比的上调/下调条形图和汇总表，
  随阈值实时更新。

### 后续建议（尚未实现）

1. **报告和导出只包含当前显示的那个对比**（`project$bundles$diff` 是单对比）。
   建议让 `export_report()` / `export_script()` 遍历 `all_bundle` 中的所有对比，
   `export_bundle()` 按对比加前缀写文件。
2. **对比之间的重叠**：`n_shared` 只给出了数量，可以加 UpSet 图，
   例如直接从 `summarize_diff_contrasts()` 的命中集合生成。
3. **全两两比较、自定义对比**（例如 `DrugB - DrugA`、`(A+B)/2 - Control`）：
   limma 路径只需要把 `makeContrasts()` 的对比字符串开放出来。
4. **在导入时记录组别列和参照水平**：写入 `omics_input` 的属性，
   让 QC、Differential、Integration 使用同一个默认值。
5. **ANOVA 进入 UI**，作为"哪些特征在任意组间有差异"的全局筛选，再用事后对比细看。
6. **多对比富集比较**：对每个对比分别富集，画一张 pathway × 对比的点图
   （clusterProfiler 的 `compareCluster` 就是这个思路）。
