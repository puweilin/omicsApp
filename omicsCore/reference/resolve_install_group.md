# Resolve a Suggests group into its package list

Resolve a Suggests group into its package list

## Usage

``` r
resolve_install_group(group)
```

## Arguments

- group:

  One of `"rnaseq"`, `"proteomics"`, `"enrichment"`, `"imputation"`,
  `"viz"`, `"persistence"`, `"all"`.

## Value

Character vector of package names.
