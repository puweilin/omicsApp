# Where the symbol table came from

Recorded in the import report and the analysis report, because a result
that depends on gene names should be able to say which vintage of gene
names produced it.

## Usage

``` r
hgnc_map_provenance()
```

## Value

A single string, or `NA_character_` when no table is bundled.
