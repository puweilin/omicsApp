# Drop samples with missing metadata

Retains only samples whose `meta_df` rows are complete on the requested
columns.

## Usage

``` r
drop_meta_na(omics_input, cols)
```

## Arguments

- omics_input:

  A validated `omics_input`.

- cols:

  Character vector of metadata columns that must be non-`NA`.

## Value

A new `omics_input` with incomplete samples removed.
