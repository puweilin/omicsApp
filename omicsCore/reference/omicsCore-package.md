# omicsCore: Multi-Omics Analysis Engine

A headless analysis engine for proteomics and transcriptomics workflows.
Provides quality control, differential expression, pathway enrichment,
and dual-omics integration as a stateless, function-based API.

## Public API

See `vignette("getting-started", package = "omicsCore")` and the
`docs/export-manifest.md` in the source repository for the planned API
surface.
