# Subset an `omics_input` by feature IDs

Subset an `omics_input` by feature IDs

## Usage

``` r
subset_omics_features(omics_input, feature_ids)
```

## Arguments

- omics_input:

  A validated `omics_input`.

- feature_ids:

  Feature identifiers to retain.

## Value

A new `omics_input` containing the selected features.
