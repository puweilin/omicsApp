# Check paired column validity in sample metadata

Check paired column validity in sample metadata

## Usage

``` r
check_paired_col(meta_df, paired_col, object_name = "meta_df")
```

## Arguments

- meta_df:

  Sample metadata.

- paired_col:

  Pairing column name.

- object_name:

  Object label used in error messages.

## Value

Invisibly returns `TRUE` on success.
